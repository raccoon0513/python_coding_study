# Q1. 별 찍기 - 1 (백준 2438)
## 문제
첫째 줄에는 별 1개, 둘째 줄에는 별 2개, $N$번째 줄에는 별 $N$개를 찍는 프로그램을 작성하시오.

## 입력
첫째 줄에 $N$($1 \le N \le 100$)이 주어진다.

## 출력
첫째 줄부터 $N$번째 줄까지 차례대로 별을 출력한다.
```
예제 입력 1 
5
예제 출력 1 
*
**
***
****
*****
```

```python
# Q1. 별 찍기 - 1
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
N = int(input())
for i in range(1, N + 1):
    print("*" * i)
```

## 풀이과정
파이썬의 문자열 반복 기능(`*` 연산자)을 활용했다. `range(1, N + 1)`을 통해 1부터 $N$까지 반복하며, 각 줄의 번호만큼 별을 생성해 출력했다.

# Q10. 별 찍기 - 10 (백준 2447)
## 문제
재귀적인 패턴으로 별을 찍어 보자. $N$이 3의 거듭제곱($3, 9, 27, \dots$)이라고 할 때, 크기 $N$의 패턴은 $N \times N$ 정사각형 모양이다. 크기 3의 패턴은 다음과 같다.
```
***
* *
***
```
크기 $N$의 패턴은 공백으로 채워진 가운데의 (N/3)x(N/3) 정사각형을 크기 $N/3$의 패턴으로 둘러싼 형태이다.

## 입력
첫째 줄에 $N$이 주어진다. $N$은 3의 거듭제곱이다. ($N = 3^k, 1 \le k < 8$)

## 출력
첫째 줄부터 $N$번째 줄까지 별을 출력한다.

```python
# Q10. 별 찍기 - 10
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
def draw_stars(n):
    if n == 1:
        return ['*']

    stars = draw_stars(n // 3)
    result = []

    # 상단 (3등분 중 첫 번째 줄)
    for s in stars:
        result.append(s * 3)
    # 중단 (3등분 중 가운데 줄, 가운데는 공백)
    for s in stars:
        result.append(s + ' ' * (n // 3) + s)
    # 하단 (3등분 중 마지막 줄)
    for s in stars:
        result.append(s * 3)

    return result

N = int(input())
print('\n'.join(draw_stars(N)))
```

## 풀이과정
분할 정복(Divide and Conquer)과 재귀를 사용해야 하는 문제다. $N \times N$ 배열을 9등분 했을 때, 가운데 칸만 공백으로 비우고 나머지 8칸은 $N/3$ 크기의 동일한 패턴을 반복하게 된다. 재귀 함수를 통해 가장 작은 단위인 1까지 쪼갠 뒤, 아래에서부터 위로 리스트를 합쳐가며 전체 모양을 완성했다.

## 입력
첫째 줄에 $N$이 주어진다. $N$은 항상 $3 \times 2^k$ 수이다. ($3, 6, 12, 24, 48, \dots$) ($0 \le k \le 10$)

## 출력
첫째 줄부터 $N$번째 줄까지 별을 출력한다.
```
예제 입력 1
```

```python
# Q11. 별 찍기 - 11
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
import sys

def draw_stars(n):
    if n == 3:
        return ["  * ", " * * ", "*****"]
    
    stars = draw_stars(n // 2)
    result = []
    
    # 상단 (삼각형 1개)
    for s in stars:
        result.append(" " * (n // 2) + s + " " * (n // 2))
    # 하단 (삼각형 2개)
    for s in stars:
        result.append(s + " " + s)
        
    return result

N = int(sys.stdin.readline())
print("\n".join(draw_stars(N)))
```

## 풀이과정
가장 작은 단위인 높이 3짜리 삼각형을 기본 블록으로 삼아 재귀적으로 확장하는 방식을 사용했다. 높이가 $N$일 때, 상단에는 $N/2$ 크기의 삼각형이 하나 위치하고, 하단에는 $N/2$ 크기의 삼각형 두 개가 공백 하나를 사이에 두고 나란히 배치되는 규칙을 코드로 구현했다.

# Q18. 별 찍기 - 18 (백준 10993)
## 문제
예제를 보고 규칙을 유추한 뒤 별을 찍는 프로그램을 작성하시오. $N$이 홀수면 정삼각형, 짝수면 역삼각형 모양의 프랙탈 구조가 나타난다.

## 입력
첫째 줄에 $N$($1 \le N \le 10$)이 주어진다.

## 출력
첫째 줄부터 해당되는 줄까지 별을 출력한다.

```python
# Q18. 별 찍기 - 18
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
def draw_stars(n):
    if n == 1:
        return ["*"]
    
    prev_stars = draw_stars(n - 1)
    height = 2**n - 1
    width = 2**(n + 1) - 3
    result = [[" "] * width for _ in range(height)]
    
    if n % 2 == 1:  # 홀수: 정삼각형
        # 바닥면
        for j in range(width):
            result[height - 1][j] = "*"
        # 양쪽 빗변
        for i in range(height - 1):
            result[i][width // 2 - i] = "*"
            result[i][width // 2 + i] = "*"
        # 이전 단계 패턴 삽입
        start_row = 2**(n - 1) - 1
        for i in range(len(prev_stars)):
            for j in range(len(prev_stars[i])):
                result[start_row + i][2**(n - 1) + j - 1] = prev_stars[i][j]
    else:  # 짝수: 역삼각형
        # 윗면
        for j in range(width):
            result[0][j] = "*"
        # 양쪽 빗변
        for i in range(1, height):
            result[i][i] = "*"
            result[i][width - 1 - i] = "*"
        # 이전 단계 패턴 삽입
        for i in range(len(prev_stars)):
            for j in range(len(prev_stars[i])):
                result[1 + i][2**(n - 1) + j - 1] = prev_stars[i][j]
                
    return ["".join(row).rstrip() for row in result]

N = int(input())
print("\n".join(draw_stars(N)))
```

## 풀이과정
재귀를 활용해 $N$ 단계의 삼각형을 그린다. $N$의 홀짝 여부에 따라 삼각형의 방향이 바뀌며, $N-1$ 단계의 패턴이 현재 단계의 특정 위치에 삽입되는 구조다. 가로와 세로 길이는 지수적으로 증가하며($H = 2^N - 1$, $W = 2 \times H - 1$), 리스트를 이용해 도화지처럼 공간을 확보한 뒤 별을 채워 넣는 방식을 사용했다.

## 입력
첫째 줄에 $N$($1 \le N \le 100$)이 주어진다.

## 출력
첫째 줄부터 해당되는 줄까지 별을 출력한다.

```python
# Q22. 별 찍기 - 22
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
def solve():
    N = int(input())
    if N == 1:
        print("*")
        return

    width = 4 * N - 3
    height = 4 * N - 1
    grid = [[" "] * width for _ in range(height)]

    x, y = width - 1, 0
    grid[y][x] = "*"
    
    # 방향: 좌, 하, 우, 상
    dx = [-1, 0, 1, 0]
    dy = [0, 1, 0, -1]
    dir = 0
    
    dist = width - 1
    # 소용돌이 그리기
    while True:
        for _ in range(dist):
            x += dx[dir]
            y += dy[dir]
            grid[y][x] = "*"
        
        if dist == 2 and (dir == 1 or dir == 3): break
        
        # 첫 방향 전환(좌->하)만 거리가 그대로고, 이후로는 2번마다 거리가 2씩 감소
        if dir == 0 or dir == 2:
            pass
        else:
            dist -= 2
            
        dir = (dir + 1) % 4
        if dist <= 0: break

    for row in grid:
        print("".join(row).rstrip())

solve()
```

## 풀이과정
매우 복잡한 소용돌이 패턴이다. $N=1$일 때는 별 하나만 출력하는 예외 처리가 필요하다. 그 외에는 도화지(`grid`)를 만들고, 밖에서 안으로 달팽이 숫자를 채우듯 방향을 바꿔가며 별을 채웠다. 행의 끝에 불필요한 공백이 있으면 안 되므로 `.rstrip()`을 사용하여 출력했다.

```python
    if sum(divisors) == n:
        print(f"{n} = {' + '.join(map(str, divisors))}")
    else:
        print(f"{n} is NOT perfect.")
```

## 풀이과정
반복문을 통해 자신($n$)을 제외한 모든 약수를 찾아 리스트에 저장했다. `sum()` 함수로 약수들의 합을 구한 뒤 $n$과 비교하여 완전수 여부를 판단했다. 완전수인 경우 `' + '.join()`을 사용하여 약수들을 지정된 형식으로 이어 붙여 출력했다.

```python
# Q69. 동전 1
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
n, k = map(int, input().split())
coins = [int(input()) for _ in range(n)]
dp = [0] * (k + 1)
dp[0] = 1
```

# Q70. 동전 2 (백준 2294)
## 문제
$n$가지 종류의 동전이 있다. 이 동전들을 적당히 사용해서 그 가치의 합이 $k$원이 되도록 하고 싶다. 그러면서 사용한 동전의 개수가 최소가 되도록 하려고 한다.

## 입력
첫째 줄에 $n, k$가 주어진다. ($1 \le n \le 100, 1 \le k \le 10,000$) 다음 $n$개의 줄에는 각각의 동전의 가치가 주어진다.

## 출력
첫째 줄에 사용한 동전 개수의 최솟값을 출력한다. 불가능한 경우에는 -1을 출력한다.
```
예제 입력 1 
3 15
1
5
12
예제 출력 1 
3
```

```python
# Q70. 동전 2
# -*- coding: utf-8 -*-
# UTF-8 encoding when using korean
n, k = map(int, input().split())
coins = [int(input()) for _ in range(n)]
dp = [10001] * (k + 1)
dp[0] = 0

for coin in coins:
    for j in range(coin, k + 1):
        if dp[j - coin] != 10001:
            dp[j] = min(dp[j], dp[j - coin] + 1)

if dp[k] == 10001:
    print(-1)
else:
    print(dp[k])
```

## 풀이과정
최솟값을 구해야 하므로 `dp` 테이블을 충분히 큰 값(10001)으로 초기화한 뒤 시작했다. 각 동전을 순회하며 금액 $j$를 만들 때, 현재 값과 해당 동전을 하나 더 썼을 때의 값($dp[j - \text{coin}] + 1$) 중 더 작은 값을 선택해 갱신했다. 마지막에 값이 갱신되지 않았다면 -1을 출력하도록 처리했다.
